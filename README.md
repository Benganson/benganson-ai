# Benganson AI

**Benganson AI** is an AI-powered personal assistant web application designed to help users think, learn, create, organize, and get things done.

The project is being developed as a personal engineering and software project, with the goal of exploring how AI can be combined with memory, productivity tools, file intelligence, voice interaction, and web-based research.

## 🚀 Current Version

**V1.0 — Core AI Assistant**

### Current Features

* 💬 AI-powered conversational chat
* 🧠 Personal memory
* 📁 File and document handling
* 🎙️ Voice interaction
* 🔎 Web search
* ⏰ Reminders
* 👤 User accounts and login
* 🗂️ Per-user data and conversation history
* 💾 Persistent data storage
* ✨ ChatGPT-style message composer and tool menu

## 🛠️ Technology Stack
